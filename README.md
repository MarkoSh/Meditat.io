# Meditat.io

Медитации и дыхание на RU/EN/TH: практики с голосом, дыхательные ритмы, таймер с колоколом, что известно науке. https://meditatio.dateonymous.com/ (постоянный домен — позже, через файл `.domain` на сервере).
Общая схема семейства, офлайн и выкладка — в [README ThaiFast](https://github.com/MarkoSh/ThaiFast#readme).

Самостоятельный сайт: всё в `index.html`.

- `PRACTICES` — практики со сценарием `script: [[секунда, tri(ru, en, th)], ...]`; это единственный источник текстов.
- `BREATHS` — дыхательные ритмы по фазам; `SCIENCE`, `SAFETY`, традиции — карточки с DOI-источниками и метками доказательности.
- Колокол — WebAudio, 432 Гц (на странице честно сказано, что особой пользы у 432 Гц не доказано).
- Статистика — `localStorage` `md:log`, сессия засчитывается от 30 секунд.

## Голос

Файл `audio/<язык>/<id практики>.mp3` автоматически заменяет текст на экране. Как записывать — [voice/README.md](voice/README.md).
Лист для записи пересобирается после правки сценариев: `node tools/scripts.js ru > voice/scripts-ru.md`.

Перед коммитом: `python3 ../ThaiFast/tools/offline.py .`. Иконки (концентрические круги) нарисованы вручную: `favicon.svg`, PNG из него через ImageMagick.
